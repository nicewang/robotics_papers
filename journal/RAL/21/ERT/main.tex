\section{Overview: Core Questions and Answers}
                           
\paragraph{(1) What is the problem?} 
\begin{itemize}
  \item Motion Planning from \textbf{Prior Experiences}
  \item \textbf{Generalizability:} Generalize prior knowledge (experiences) even to \textbf{notably different} task instances.
\end{itemize}

\paragraph{(2) Why need to solve this problem?}
\begin{itemize}
  \item Robots planning from \textit{scratch} leads to \textit{unnecessarily long planning times}.
  \item While leveraging prior experiences can \textbf{speed up} the motion planning process, existing learning-based and experience-based methods \textit{fail} or \textit{generalize poorly} when the new task \textit{differs significantly} from the \textit{stored} experiences (i.e. \textit{non-experienced regions}).
  \item Making \textbf{prior} knowledge \textbf{truly reusable} across \textbf{diverse task variations} remains an open challenge.
\end{itemize}

\paragraph{(3) How is it different from prev.?}
\begin{itemize}
  \item Previous experience-based \textit{path-centric} planners (like \textit{Lightning} or \textit{Thunder}) use prior experiences \textit{``rigidly''} by recalling \textit{exact existed motions} and simply repairing disconnected states, which requires \textit{a vast library of closely related experiences}.
  \item In contrast, this approach treats experiences as \textbf{``decomposable''} and \textbf{``malleable''}. Instead of \textit{copying} exact paths, it breaks a prior path into smaller parts (\textbf{``micro-experiences''}) and \textbf{semi-randomly morphs} them using affine transformations (\textbf{shear} and \textbf{shift}) to explore new situations.
\end{itemize}

\paragraph{(4) Why is it better than prev.? (Advantages)} 
\begin{itemize}
  \item The proposed method can successfully solve \textbf{highly novel} task instances using just a \textbf{single} prior path experience, whereas \textit{state-of-the-art} planners fail even with \textit{vast repertoires of experiences}.
  \item It \textbf{significantly outperforms} existing methods in both \textbf{success rate} and \textbf{planning time}, particularly in challenging scenarios involving \textbf{new obstacles} or \textbf{narrower geometries}.
\end{itemize}

\paragraph{(5) What is the approach itself?}
\begin{itemize}
  \item 2 \textbf{Tree Sampling-based Planners}:
  \begin{itemize}
    \item \textbf{\textit{ERT}} (Experience-driven Random Trees)
    \item \textbf{\textit{ERTConnect}} (\textbf{bi-directional} version of ERT)
  \end{itemize}
  \item Iterative Traj. Generation Process via ERT (ERTConnect):
  \begin{itemize}
    \item Prior $\bm{\xi_D}$ Selection according to \textit{Eq. 4}
    \item ${\bm{\xi_D \to \xi'_D}}$ \textbf{``Mapping'':} The approach maps \textbf{selected single prior} path ${\bm{\xi_D}}$ to a new path ${\bm{\xi'_D}}$ \textit{whose initial and final configurations match the task's start and goal}.
    \item Iteration: Iteratively extracts \textbf{segments (``micro-experiences'')} from mapped $\bm{\xi'_D}$.
    \begin{itemize}
      \item $\bm{\psi_{\mathcal{D}} \leftarrow \xi'_{\mathcal{D}}(\alpha_{\text{init}}, \alpha_{\text{targ}})}$ with 2 options:
      \begin{itemize}
        \item Option \textbf{\textit{``Connect''}}: With 2 particular \textbf{given} states $\bm{<s_{init}, s_{targ}>}$.
        \item Option \textbf{\textit{``Explore''}}: \textbf{Explore} the best way to continue the task from a given state $\bm{s_init}$.
      \end{itemize}
      \item In each iteraion, an \textbf{affine transformation} is applied to \textbf{morph} the segment (``micro-experience'') $\bm{\psi_{\mathcal{D}}}$, generating \textbf{smooth deformations} via \textbf{shear} and \textbf{shift} parameters to create task-relevant motions.
      \item \textbf{Concatenation (Connecting):} Each segment is \textit{incrementally} concatenated to build a \textbf{valid motion tree} \textit{connecting the start and goal}.
    \end{itemize}
  \end{itemize}
  \item Highlighted Novelty:
  \begin{itemize}
    \item \textbf{\textit{``Divide and Conquer''}} alike:
    \begin{itemize}
      \item \textbf{Divide -> Decompose:} Decompose a single prior path to smaller ``micro-experiences''.
      \item \textbf{Conquer -> Compose:} Iteratively morph each ``micro-experiences'', and then finally compose to a valid motion tree (connecting the start and goal).
      \item Effect: \textit{``rigid''} to \textbf{``agile''}
    \end{itemize}
  \end{itemize}
\end{itemize}

\paragraph{(6) What are the applications of it?} 
\begin{itemize}
  \item Fully-autonomous robotic manipulation \& motion planning, particularly in \textbf{``recurrent''} tasks such as a robotic arm performing \textbf{\textit{shelf-stocking}}.
  \item Exp Platforms:
  \begin{itemize}
    \item Real-world Fetch (with a \textit{7-DoF arm}, planning in an 8-DoF configuration space)
  \end{itemize} Synthetic Exps: Simulation envs combined with \textit{OMPL} and \textit{MoveIt}.
\end{itemize}
